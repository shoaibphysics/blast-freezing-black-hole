# Figure 2 component images

These inputs are used by the canonical builders in `code/scripts/`.
They are preserved source images, not a generated-output directory.

| Input | Current manuscript panel | Role |
|---|---|---|
| `fig3b.png` | Figure 2(c) | Supplied Penrose drawing |
| `fig3c_formation_gate_color_map.png` | Figure 2(d) | Saved formation map, also independently regenerated by the geometry check |
| `fig3d.png` | Figure 2(f) | Supplied Penrose drawing |

Historical numbers in filenames do not determine the current figure number.
The finished figure embedded by LaTeX is `paper/figure2_bulk_geometry.pdf`.
Run the grouped command from the repository root:

```sh
.venv/bin/python code/figure-reproduction/reproduce_figures.py
```

New figures go to `code/figure-reproduction/generated/figures/`.
See the [figure map](../../figure-reproduction/README.md) for all five main
figures and both supplementary diagrams.
