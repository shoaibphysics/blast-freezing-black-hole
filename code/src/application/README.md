# Applications to infalling information

`bulk_mi.py` combines finite-p replica correlators with bulk reconstruction to
compute the probe mutual information. `infalling_operator_size.py` contains
auxiliary circuit-based operator-size routines. The manuscript's Figure 3 instead
uses the eta/chi size-response functions in `code/src/large_p/evap_syk.py` and
the reconstruction kernels. The canonical plotting driver is
`code/scripts/generate_paper_figures.py`, run through the
[figure guide](../../figure-reproduction/README.md).

Formal definitions and derivations are in the scientific supplement, Secs. S4–S5.
