# Large-p analytic calculations

This module contains analytic two-point functions, source matching, formation
profiles, and four-point responses used for operator size. `evap_syk.py` is the
main evaporation correlator and size-response entry point; `formation_sources.py`
constructs the formation protocol. Formal conventions are in the scientific
supplement, Secs. S3, S4, and S6.

Use the [figure guide](../../figure-reproduction/README.md) for the distinct
geometry, size/two-point, and finite-p presets.
